# Mini Library Management System

A simple command-line library management system built using Python.

## Features

* Add books
* Search books by title
* Borrow and return books
* Track book availability and borrowers
* Set a 14-day borrowing period
* Check for overdue books
* Display library summary
* Save borrowing records to a text file
* Store library data using JSON
* Validate invalid menu input

## Files

* `library.py` - Main Python program
* `library_data.json` - Stores books, users and borrowing records
* `borrowing_records.txt` - Generated borrowing records
* `obstacle_log.md` - Development obstacles and solutions

## How to Run

Make sure Python 3 is installed.

Run:

```bash
python3 library.py
```

Follow the menu displayed in the terminal to use the system.
