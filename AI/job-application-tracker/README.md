# Personal Job Application Tracker

A Python-based CLI application for tracking job applications and generating application insights.

## Features

- Add new job applications
- Search applications by status
- Search applications by company
- Update application status
- View application summary
- View companies and roles currently at Interview stage
- Save applications and summary to a text report
- Validate application statuses

## Files

- `job_tracker.py` - Main Python program
- `application_data.json` - Sample application data
- `job_tracker_report.txt` - Generated application report
- `obstacle_log.md` - Development obstacle log

## How to Run

```bash
python3 job_tracker.py
