# Food Delivery Order Processor

A simple Python program that processes food delivery orders and generates final bills.

## Features

* Stores menu items and sample orders using dictionaries and lists
* Calculates order totals
* Applies discounts to qualifying orders
* Adds delivery charges
* Handles invalid menu items
* Handles empty orders
* Identifies the highest-value order
* Generates a daily sales summary
* Saves the sales summary to a text file

## Files

* `order_processor.py` - Main Python program
* `order_data.json` - Menu and sample order data
* `sales_summary.txt` - Generated daily sales summary
* `obstacle_log.md` - Development obstacles and solutions

## How to Run

Make sure Python 3 is installed.

Run:

```bash
python3 order_processor.py
```

The program processes the sample orders and generates `sales_summary.txt`.
