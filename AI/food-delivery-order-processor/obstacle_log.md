# Obstacle Log

## 1. Working with Nested Data

The orders contained multiple items and quantities. I learned how to access nested lists and dictionaries to calculate the total for each order.

## 2. Invalid Orders

The program initially needed a way to handle invalid menu items and empty orders without stopping. I added validation before processing each order.

## 3. Discount Calculation

Calculating the final bill required separating the order total, discount, and delivery charge. I created separate functions for each calculation.

## 4. Highest-Value Order

I needed to compare the final values of all valid orders. I used a variable to keep track of the highest value and its order ID.

## 5. Sales Summary

The calculated results needed to be saved outside the program. I generated a text file containing the total orders, total revenue, and highest-value order.
